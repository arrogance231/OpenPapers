# Acknowledgements

OpenPapers integrates with the following external services and open-source projects. They remain independent projects owned and maintained by their respective organizations and communities.

## Scholarly infrastructure

- [Semantic Scholar](https://www.semanticscholar.org/) and its [API](https://api.semanticscholar.org/) provide paper, author, reference, citation, and recommendation data. Semantic Scholar is developed by the Allen Institute for AI.
- [OpenAlex](https://openalex.org/) and its [API documentation](https://docs.openalex.org/) provide open scholarly metadata and citation relationships.
- [arXiv](https://arxiv.org/) and its [API](https://info.arxiv.org/help/api/) provide preprint metadata and discovery.
- [Crossref](https://www.crossref.org/) provides DOI and bibliographic metadata through its public services.

## Machine-learning and developer resources

- [Hugging Face](https://huggingface.co/) provides model and dataset hub infrastructure used for discovery and metadata retrieval.
- [GitHub](https://github.com/) provides repository search, metadata, revision, and content endpoints used for bounded implementation discovery.

## Software infrastructure

- [Model Context Protocol](https://modelcontextprotocol.io/) SDK packages provide the MCP server and transport interfaces.
- [GROBID](https://github.com/kermitt2/grobid) provides optional TEI-based scholarly PDF parsing.
- [PostgreSQL](https://www.postgresql.org/) and [pgvector](https://github.com/pgvector/pgvector) provide optional durable relational and vector storage.
- [Node.js](https://nodejs.org/), [TypeScript](https://www.typescriptlang.org/), [Zod](https://zod.dev/), and [Vitest](https://vitest.dev/) provide the runtime, language, validation, and testing foundations.
